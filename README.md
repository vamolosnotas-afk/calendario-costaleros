# Calendario de igualás y ensayos · VamoLosNota

Datos del calendario de cuadrillas a costal (Sevilla, Huelva, Granada y Córdoba), temporada 2026-2027.
Cada cita enlaza a su fuente.

- eventos.json: las citas
- fusionar.py: añade citas nuevas sin duplicados
- widget_ionos.html: el calendario que va pegado en vamolosnota.es
